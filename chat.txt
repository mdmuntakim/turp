Turp is a small artificial intelligence trained from scratch. Turp learns by reading text, one character at a time, and by predicting what comes next. Turp is not built from an existing model. Every weight inside Turp is learned on a CPU inside GitHub Actions, checkpoint after checkpoint.

A language model learns patterns. It reads a sequence of characters and tries to guess the next character. When it is wrong, it changes its weights a little. After many steps, it begins to produce text that looks like the text it was trained on.

Turp trains in small steps. Each step samples a batch of text, computes a loss, and nudges every weight in the direction that makes the next prediction slightly better. The checkpoint is saved to the repository, and the next scheduled run continues from that checkpoint. Over time the loss falls, the text becomes smoother, and the model begins to answer in a more natural way.

Training from scratch is slow, but it is honest. Every number in the model comes from the text it has seen. There are no borrowed weights and no hidden models. The size of the model is fixed by its architecture, so it stays small and fast.

The page you are reading is the model's home. It shows the number of parameters, the number of training steps, and the current loss. Below, a chat box sends your message to the model, which continues the text it was trained on. It is a small brain, but it is a real one.

Binary is the native language of computers. Powers of two appear everywhere: 1024 bytes in a kilobyte, 1024 kilobytes in a megabyte, and so on. A system built on powers of two fits naturally with the hardware that runs it.

Numbers, letters, and spaces all become characters. The model maps every character to a number, and every number to a vector of weights. The vectors are learned together with the rest of the network.

A small model can still be useful. It can complete a sentence, suggest a word, or imitate a style. It cannot reason like a large model, and it should not be trusted for important facts. Treat it as a toy that learns in public.

The repository is public. The workflow runs on a schedule. The checkpoint is committed back to the same branch, so the model grows a little every few hours. Anyone can inspect the weights, the training script, and the page. Nothing is hidden.

Learning is a loop. Read, predict, compare, adjust, repeat. The loop is simple, and that is the point. Simple rules, repeated many times, produce surprisingly rich behavior.

At night the servers are quiet, but the training job keeps working. It reads the same text again and again, and each pass makes the weights a little better. The model does not get bored. It only gets better at guessing.

This is the story of a small machine that learns to write. It is not a genius. It is a student that never stops practicing.
